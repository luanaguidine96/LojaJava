#  Loja Java no TERMINAL

Um projeto de **loja online desenvolvido em Java**, criado durante meus estudos autodidatas de Programação Orientada a Objetos (POO).

##  Sobre o projeto

Este projeto simula o funcionamento básico de uma loja, permitindo cadastrar produtos, criar pedidos e interagir com diferentes informações através de um sistema executado pelo terminal.

O objetivo principal foi **praticar Java e entender melhor como organizar um projeto utilizando classes, objetos, métodos, atributos e encapsulamento**.

##  Tecnologias

* Java
* Programação Orientada a Objetos (POO)
* Git e GitHub

##  O que estou praticando

Neste projeto estou aprendendo e colocando em prática conceitos como:

* Classes e objetos
* Atributos e métodos
* Encapsulamento
* Construtores
* Getters e setters
* `ArrayList`
* Estruturas de repetição
* Estruturas condicionais
* `Scanner`
* Organização de classes
* Relacionamento entre objetos

##  Sobre o desenvolvimento

Este é um projeto de aprendizado, então ele está em constante evolução.

Durante o desenvolvimento, utilizei a **internet como fonte de pesquisa e aprendizado**, principalmente para entender conceitos e resolver dúvidas. Porém, **entendo o código que está presente no projeto e consigo explicar o funcionamento das partes que desenvolvi**.

Estou usando este projeto para evoluir cada vez mais em Java e construir uma base melhor em programação.

## Próximos passos

Pretendo continuar melhorando o projeto conforme avanço nos estudos, adicionando novas funcionalidades e aplicando conceitos mais avançados de Java.
